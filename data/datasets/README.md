# Sample Datasets

This folder contains small, schema-friendly sample molecule datasets for local development and UI/testing flows.

- `demo.csv` - minimal demo dataset used by the app
- `drugbank.csv` - sample DrugBank-style molecules
- `zinc.csv` - sample ZINC-style molecules

Columns follow the common molecule shape used across the project:

- `molecule_id`
- `smiles`
- `mw`
- `logp`
- `qed`
- `tpsa`
- `hbd`
- `hba`
